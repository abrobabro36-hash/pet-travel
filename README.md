# 🐾 PetTravel Finder

**PetTravel Finder** is a minimalist and clean web interface designed for quick and hassle-free searching of pet-friendly hotels and accommodations worldwide. 

The user interface features a modern, soft neumorphic design (Neumorphism), delivering a smooth visual experience without heavy or cluttered graphical elements.

## ✨ Features
* 🔍 **Global Hotel Search:** Seamlessly connected with Booking.com search parameters, automatically applying the "traveling with pets" filter.
* 🌿 **Neumorphic UI:** Soft shadows, smooth custom toggles, and unified input fields for a modern look.
* 📱 **Fully Responsive:** Completely optimized for desktops, tablets, and mobile devices.
* 💡 **Travel Tips:** Built-in helpful hints and reminders on how to prepare your pet for an upcoming trip.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Custom Properties, CSS Grid, Flexbox, Neumorphic shadows)
* JavaScript (Vanilla JS, URLSearchParams API)

## 🚀 How to Run Locally
Simply clone the repository or download the `index.html` file, then open it in any modern web browser. No installation or local server required.
